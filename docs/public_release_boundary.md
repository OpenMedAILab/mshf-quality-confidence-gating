# Public release boundary

This repository contains analysis code, a release-safe configuration, aggregate bootstrap CSVs in `results/bootstrap/`, aggregate tables in `tables/`, and an aggregate figure in `assets/`.

It excludes raw fundus images, preprocessed image caches, dataset archives, patient/eye/image-level manifests and predictions, model checkpoints, credentials, manuscript submission files, and internal reviews. Those inputs are needed for full image-level reproduction and must be obtained or generated independently under the source providers' terms.

The PNG figure is derived from aggregate retention results and contains no fundus images. No individual-level derived records are released here.
